# Question list sharing uses claimable links and snapshots

Question list sharing uses reusable, capped share links that recipients claim with permanent accounts. The shared question set and any included answers are snapshotted when the owner shares, and recipient replies are explicit latest-only snapshots. We chose this over username invites, public links, and live answer sharing because it keeps sharing ergonomic while avoiding silent answer changes, recipient-to-recipient visibility, and broad public access.
